# Фотожурнал разборки и экспериментов

**Дата:** 7 ноября 2026 года. Оригинальные фотографии сделаны во время разбора и проверок. В README не выдаются снимки рекламных аккумуляторов за собственные испытания.

## Снимки и что на них видно

| № | Содержание | Наблюдение |
| --- | --- | --- |
| 01 | Общий вид FLIGHT сверху | X-рама, складные винты, зелёные вставки |
| 02 | Корпус снизу | Отсек питания, возможный модуль камеры |
| 03 | Трёхконтактный разъём `CAM` | Не использовать как зарядный |
| 04 | Защёлка `OPEN/CLOSE` | Доступ к отсеку батареи |
| 05 | Li-Po `CY 802540H` | 3,7 В, 600 мА·ч |
| 06 | Двухконтактный белый разъём | Проводка аккумулятора, не измерен шаг |
| 07 | Снятая плата защиты | Предположительно PCM, не контроллер CC/CV |
| 08 | Главная плата, компоненты | Предположительно PAN159CY, моторные ключи |
| 09 | Главная плата, обратная сторона | `ZY-860R / 2017.07.30`, `2V8 GND CLK DAT` |
| 10 | Узел мотора и шестерни | Коллекторный двигатель с редуктором |
| 11 | Квадрокоптер без верхней крышки | Четыре луча, двигатели, подсветка |
| 12 | MFRC522 | RFID 13,56 МГц — **не** RF передатчик для дрона |
| 13 | HC-серии Bluetooth UART | 2,4 ГГц Bluetooth — **не** nRF24L01 |
| 14 | Диспетчер устройств | ESP32 на COM3 / CP210x |
| 15 | G910 / ARDOR Vigour | Испытаны два режима Bluetooth |
| 16 | Mean Well RS-15-5 | 5 В/3 А, для входа 1S напрямую не подходит |

Исходные снимки и пользовательские фотографии кандидатов батарей, а также журнал Serial/PowerShell включаются в архив исходных материалов проекта. Сводные результаты и логика проверок записаны в документации, чтобы не потерялись даже без изображений.

## Статус фото

Текстовые материалы репозитория содержат описание всех ключевых кадров. Полноразмерные фотографии могут потребовать отдельной загрузки в `assets/photos`, если их нельзя передать через GitHub-коннектор напрямую. Не создавать несуществующие ссылки на файлы или картинки.
