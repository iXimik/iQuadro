# План восстановления GoSHa Drone

## Этап 0 — выполнен (07.11.2026)

- [x] Осмотр, демонтаж корпуса, фото платы с обеих сторон, приводов, старого аккумулятора и его защиты.
- [x] Установлен Arduino CLI 1.5.1 и отдельный пакет Bluepad32 ESP32 4.1.0.
- [x] ESP32-D0WDQ6 с CP210x прошит через COM3.
- [x] MOBASE G910: Bluetooth есть, HID «Keyboard» — режим gamepad не подтверждён.
- [x] ARDOR Vigour: в режиме Nintendo определён Switch Pro, четыре оси + кнопки читаются.
- [x] При глубоком разряде/вздутии старый Li-Po утилизирован.

## Этап 1 — питание и механика

- [ ] Проверить силовую проводку и отсутствие короткого замыкания по входу питания.
- [ ] Подобрать 1S Li-Po 3,7 В / 600 мА·ч с токоотдачей под моторы, весом/габаритами под отсек.
- [ ] Подобрать зарядник Li-Po CC/CV 4,2 В и подтвердить полярность разъёма.
- [ ] Без пропеллеров проверить логику ZY-860R от лабораторного БП с лимитом тока.
- [ ] Замерить ток логики и ток двигателей отдельно, проверить редукторы.

## Этап 2 — тестовый пульт

- [ ] Универсальный лог геймпада Vigour, не выводить одинаковые значения сотни раз.
- [ ] Калибровать центры и deadzone осей; установить физические назначения кнопок.
- [ ] Жёстко запретить непреднамеренный газ, реализовать E-STOP и таймауты.

## Этап 3 — радиопротокол

- [ ] Купить nRF24L01+ и проверить его по SPI **отдельно** от квадрокоптера.
- [ ] Изучить PAN159CY/ZY-860R и существующие реализации в DIY Multiprotocol TX.
- [ ] Найти и подтвердить реальный протокол привязки и пакетов. Совпадение PAN159CY или частоты **не означает** поддержку GW008.
- [ ] Если родное радио непригодно — спроектировать замену полётного контроллера с IMU.

## Этап 4 — безопасность и полёт

- [ ] Настроить fail-safe по потере как Bluetooth, так и радиосигнала ESP32 → дрон.
- [ ] Проверить безопасную последовательность arm/disarm.
- [ ] Стендовая проверка моторов **без винтов** и направления их вращения.
- [ ] Лётные испытания только в безопасной зоне при полной готовности системы стабилизации.

**Принцип GoSHa:** не выдаём гипотезы за результаты и не проверяем силовую электронику методом «ну давай подадим пять вольт, что будет».
