# Аппаратный отчёт ZY-860R

**Дата разборки:** 07.11.2026. Не путать визуальный осмотр и испытания!

## Квадрокоптер

Игрушечная четырёхмоторная рама с пластмассовыми редукторами и подсветкой. Пульт отсутствует. Из внутренних компонентов: главная плата, четыре мотора с маленькими шестернями и большими белыми шестернями, проводка, корпусные элементы, модуль камеры/подвеса (вероятно; уточнить по маркировке).

**Плата:** на обратной стороне **ZY-860R**, маркировка **2017.07.30**. Главная микросхема на лицевой стороне подписана приблизительно **PAN159CY / 1732A**. Рядом есть другой чип, который может быть IMU, но без читаемой маркировки его тип не установлен. Есть дискретные ключи привода моторов. Заметны тестовые площадки **2V8 / GND / CLK / DAT** — их назначение **не подтверждено**, нельзя подключать к GPIO без измерений. Разъём **CAM** вероятно относится к модулю камеры, а не к зарядке.

**Электродвигатели:** коллекторные, 4 штуки, привод через редукторы; фотографии демонстрируют открытые шестерни. Не установлены номинальные токи, направление вращения каждой пары, характеристики моторов. Реальный тест работы не выполнялся.

## Батарея и разъёмы

| Свойство | Исходный элемент |
|---|---|
| Тип | Li-Po, 1S |
| Маркировка | CY 802540H |
| Напряжение | 3,7 В номинально, 4,2 В полностью заряженный |
| Ёмкость | 600 мА·ч |
| Измерено | ~0,18 В на выходном разъёме |
| Состояние | Признаки вздутия, дальнейшее применение запрещено |
| Последующее действие | Утилизирован владельцем; плата защиты снята |

Плата с тремя микросхемами и металлическими полосами, снятая с ячейки, — **предположительно PCM/BMS (защита)**. Она не является подтверждённым контроллером зарядки. Не использовать для зарядки без паспортных данных.

**Замена:** `802540P, 3,7 В, 600 мА·ч, 25C` — *товарный кандидат*, реальные характеристики не измерены. `802540, 800 мА·ч` — возможен по габаритам, но не известна токоотдача. `903052, 1800 мА·ч` — слишком крупный/тяжёлый. **18650** (1S 3,6/3,7 В) допустим как **обсуждаемый стендовый** источник только с правильно рассчитанной токоотдачей и защитой, но не рекомендован как полётная батарея.

**Контакты:** 2-пиновый белый коннектор батареи; его форма похожа на JST-совместимый, продавец одного сменного элемента указывает XH2.54, однако **точная серия, шаг и полярность должны быть измерены и проверены**, одинаковый пластик не гарантирует одинаковое расположение +/−.

## Найденные сторонние радиомодули

- **RFID RC522**: 13,56 МГц, считывание меток; не подходит для радиоуправления данным квадрокоптером.
- **Bluetooth UART CSR BC417**: тип HC-05/HC-06 на вид, передаёт последовательные данные по Bluetooth, не формирует неизвестный протокол ZY-860R.
- **nRF24L01+**: рассматривался для будущего ESP32-пульта; **пока не установлен**. Взаимодействие с ZY-860R требует отдельного исследования протокола.

## Испытание питания: не выполнено

1. Удалить **все четыре пропеллера** и надёжно закрепить раму.
2. Без аккумулятора осмотреть проводку и проверить отсутствие явного КЗ по батарейной линии.
3. Предпочтительно подключить отдельный лабораторный блок питания к батарейному входу на **3,7 В** с ограничением тока и проверенной полярностью. Начать с низкого токового ограничения для питания логики, не запускать моторы сразу.
4. При срабатывании ограничения тока или нагреве — отключить, установить причину.
5. **Не** питать моторы через ESP32, USB, breadboard или слабые провода. Для динамического теста моторов потребуется достаточный ток и отдельный предохранитель/ограничение, а также проверенный failsafe.
